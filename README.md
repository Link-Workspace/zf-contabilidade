# ZF Contabilidade — Website institucional

Projeto estático pronto para abrir no VS Code.

## Como abrir

1. Extraia a pasta `zf-contabilidade-site`.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador ou use a extensão **Live Server**.

## Estrutura

- `index.html` — página inicial.
- `servicos.html` — serviços de administração de condomínios e contabilidade.
- `area-cliente.html` — modelo visual de área do cliente.
- `contato.html` — contatos por região e formulário visual.
- `assets/css/style.css` — estilos do site.
- `assets/js/main.js` — menu mobile, animações e interações.
- `assets/img/` — logo e ilustrações do projeto.

## Observações

A área do cliente e o formulário são demonstrativos visuais. Para usar em produção, será necessário integrar com backend, autenticação, banco de dados, envio de e-mail ou WhatsApp.
